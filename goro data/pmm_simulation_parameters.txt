PropertyPMM Goro flow simulation parameters

Required parameters
1. initial_base_liquidity_bps
   Fraction of the 706,912 token supply deposited into the PMM initially.
   Baseline: 3,000 bps (30%). Test 1,000 / 2,000 / 3,000 bps.

2. initial_valuation_price
   Guide valuation in quote-token units per base token.
   Baseline: 10,000 sUSD per token, specified for this simulation because the
   Goro dataset has no trade price. Test a valuation range around that value.

3. k
   PMM curve/slippage parameter. The contract requires 0 < k < 1.
   Baseline: 0.10. Test 0.05 / 0.10 / 0.20.

4. lp_fee_rate and maintainer_fee_rate
   Fees charged by PropertyPMM.
   Baseline: 0.50% LP fee and 0% maintainer fee.

5. market_participation_bps
   Percentage of observed Goro daily flow assumed to route through this PMM.
   Baseline: 10,000 bps (100%), because this scenario assumes the PMM is the
   only market. Lower values remain useful sensitivity scenarios.

6. execution order
   Run sell-then-buy and buy-then-sell for every daily aggregate. The source
   has no intraday sequence, while PMM is path-dependent. Report both outcomes.

Fixed data treatment
- Token: ERC-1155 ID 18; total supply: 706,912.
- Input: Goro market data via Dune query 6936221.
- Main sample: 2024-12-25 to 2026-06-23 (post-launch).
- amount_in is sell flow; amount_out is buy flow.
- No synthetic primary-sale volume subtraction.
